# DataForge — End-to-End Retail Analytics Platform

**Developed by Rania Boudjemadi**

## Project Overview
DataForge is a retail data engineering and analytics platform built using Python, SQLite, DuckDB and dbt Core.

## Architecture
- Python data generation and ingestion
- SQLite warehouse and data validation
- DuckDB analytical database
- dbt staging and analytics models
- Automated data quality and reconciliation tests
